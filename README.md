# RL Map Loader – downloads

Load Rocket League workshop maps into Underpass, with an in-game overlay (F3). For Windows and Linux.

**[Download the latest version](https://github.com/GAGBI123/rl-map-loader-releases/releases/latest)**

- **Windows:** `RLMapLoader-Windows.exe` – just run it. (`RLMapLoader-Windows-NET9.exe` is the small build for PCs
  with the .NET 9 Desktop Runtime.)
- **Linux:** `RLMapLoader-Linux.tar.gz` – extract it and open `rl-map-loader` once. It adds RL Map Loader to your app
  menu; open it from there afterwards.

Installed copies update themselves (Settings → Updates). This repository only holds the downloads and the update feed
(`latest.json` in each release).
